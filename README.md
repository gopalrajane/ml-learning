# Machine Learning Learning

A day-wise collection of Jupyter notebooks documenting practical study of machine learning and data science concepts.

## Topics

- Data loading, analysis, and exploratory data analysis
- Data cleaning, missing values, and outlier handling
- Feature engineering, encoding, scaling, and transformation
- Scikit-learn pipelines and column transformers
- Dimensionality reduction with PCA
- Linear, multiple, and polynomial regression
- Gradient descent and regularization
- Logistic regression and classification metrics
- Naive Bayes and decision trees

## Structure

Each day has a separate folder containing notebooks and related practice files.

```text
ml-learning/
├── Day01 - .../
├── Day02 - .../
├── ...
└── README.md
```

## Getting Started

Clone the repository and open the notebooks in Jupyter Notebook or VS Code.

```bash
git clone https://github.com/gopalrajane/ml-learning.git
cd ml-learning
```

Install the libraries used by a notebook before running its cells. Dataset paths may need to be adjusted based on your local setup.
